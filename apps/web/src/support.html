Mobile Support Safety Boundary

Allowed in this phase:
Show Gmail connector status, connected/disconnected state, last sync timestamps, redacted sync errors, token health state, ticket review card, suggested reply review card, approval checklist, and approve/reject controls for existing proposed actions.

Not allowed in this phase:
No Gmail API client, no Gmail OAuth route, no Gmail send/modify scope, no email sending, no support auto-reply, no support send executor, no token value display, and no raw provider payload display. Approve/reject records internal action status only.
