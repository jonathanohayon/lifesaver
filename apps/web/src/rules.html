Step 1 — Choose action type

Choose which future action family the policy would apply to. This does not enable the action.

Step 2 — Choose platform/channel

Scope the policy to a safe platform/channel. Empty values are avoided so the future rule shape is predictable.

Step 3 — Add condition

Choose one Phase 6.4 condition operator. More complex condition builders come later.

Tip: for risk_below, use low, medium, high, or critical. For amount/confidence operators, use a number.

Step 4 — Choose decision

Auto-approve in this wizard is only a future policy decision preview. It does not trigger execution in this package.

Step 5 — Set caps

Caps are included in the preview JSON using the Phase 6.6 cap names. Empty values are omitted.

Step 6 — Review

Review the policy shape before saving the local preview draft. This JSON is not sent to the backend in Phase 7.2.
