How It Works

1. Customer signs up
Creates a private workspace on app.mydomain.com.
2. Customer connects Triple Whale
The customer owns and manages their own API key.
3. LIFE.SAVER reads metrics
Backend stores raw payloads separately from normalized dashboard metrics.
4. Claude advises safely
Claude API is platform-owned and server-side only.
