Version: v0.6.0
Phase: 5.7
Status: Backend safety contract only

================================================================================
PURPOSE
================================================================================

Phase 5.7 makes the future policy engine pause-aware.

The rule is simple:

- If pause_all_autonomy is active, the policy layer must never return auto_approve.
- If a category pause is active, the policy layer must never return auto_approve for that category.
- If pause state cannot be read, the policy layer must fail closed and return block or ask.

This phase does not add a full policy table, rule builder, rules UI, auto-run engine, executor, or external write connector.

================================================================================
WHY THIS IS NEEDED
================================================================================

V2 will eventually include rules such as:

- Auto-publish approved-style content.
- Auto-send safe FAQ replies.
- Auto-adjust small ad budgets inside hard caps.

Those rules are powerful. They must always be subordinate to the master pause and category pause settings.

Even if a future policy says "auto_approve", active pause must override it.

================================================================================
POLICY DECISION RULES
================================================================================

When no pause is active:

- ask remains ask.
- block remains block.
- auto_approve may continue to later policy/cap checks.

When global pause is active:

- ask remains ask.
- block remains block.
- auto_approve becomes ask by default.
- auto_approve may become block if strict enforcement mode is requested.

When category pause is active:

- Same as global pause, but only for the matching action category.

When pause state cannot be read:

- Decision becomes block.
- autoApprovalAllowed=false.
- executorExecutionAllowed=false.
- No external write is attempted.

================================================================================
CREATE PROPOSED ACTION INTEGRATION
================================================================================

createProposedAction() now uses the policy pause enforcement helper after reading autonomy state.

If pause is active, it forces:

- policy_decision = ask, unless a stricter block decision is used by future policy code.
- approval_required = true.

This keeps proposed actions reviewable while preventing hidden auto-approval.
