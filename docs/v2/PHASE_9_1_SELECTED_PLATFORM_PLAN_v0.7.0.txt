Phase 9.1 deliverable status: selected platform plan complete.

================================================================================
2. WHY LINKEDIN FIRST
================================================================================

The purpose of Phase 9 is not to immediately build every social connector. The purpose is to add the first real content executor carefully, starting with one content platform and manual approval only.

LinkedIn is the recommended first platform because:

1. It has a relatively clean OAuth + post creation model.
2. It allows a text-only proof before media upload complexity.
3. It is safer for the first live test than a consumer short-video platform.
4. It helps prove LIFE.SAVER's approval -> execute -> result-log path with lower operational risk.
5. It avoids starting with YouTube video upload audits, TikTok direct-post audit requirements, or Instagram media container/app-review complexity.
6. It is still commercially useful for founder thought-leadership, brand updates, announcements, investor/client updates, and product/business insights.

================================================================================
3. WHY NOT THE OTHER OPTIONS FIRST
================================================================================

Instagram:

- Strong ecommerce relevance.
- Good future target.
- More complex for first executor because real publishing generally requires Meta app setup, account/page linkage, correct permissions, media container creation, publish call, and app review considerations.
- Recommended later after the executor safety pattern is proven.

TikTok:

- Strong short-form content relevance.
- Heavier media/video workflow.
- Direct posting requires explicit user consent, content export/init flow, and audit considerations.
- Recommended later after media handling and approval patterns are stronger.

YouTube:

- Good for video publishing.
- Not ideal first because video upload, large file handling, quota, processing status, privacy status, and API compliance/audit requirements add complexity.
- Recommended later for video-specific phase.

Facebook:

- Good future target, especially if paired with Meta/Instagram.
- Page publishing depends on Meta app, page permissions, page token handling, and app review considerations.
- Recommended after Meta credential model and Instagram/Facebook combined planning.

================================================================================
6. FUTURE REAL EXECUTOR GATES
================================================================================

Before any real publish call can happen in Phase 9.6 or later, the executor must verify:

1. Workspace-scoped connected account exists.
2. Access token is available server-side only.
3. Action type is content_publish.
4. Platform is linkedin.
5. Action is manually approved by owner/admin.
6. Master pause is off.
7. Content category pause is off.
8. Emergency safe mode is off.
9. Policy decision does not block.
10. Hard caps are not exceeded.
11. Idempotency key has not already executed.
12. Payload validates against content publish schema.
13. Result is logged in action_results.
14. Failure is logged and visible.
15. Rollback behavior is defined as delete_supported, delete_not_supported, or rollback_not_supported depending on LinkedIn API support and permissions.
