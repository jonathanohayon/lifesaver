Founder explanation copy
The warning explains that pause blocks future auto-approval and executor execution while proposed actions remain reviewable.

Accessibility notes
- Buttons use native button elements.
- Category buttons expose aria-pressed state.
- Input has a placeholder and accepts a short audit reason.
- Mobile styles keep buttons full width when needed.
- Status text remains visible without relying only on color.

No-execution guarantee
The UI only calls autonomy status/pause/resume endpoints. Those endpoints update database flags and audit logs only.
