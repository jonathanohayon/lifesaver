LIFE.SAVER v0.4.1 — Production Environment Variables Checklist

DO NOT COMMIT REAL VALUES.
Store these in the hosting provider's environment variable manager.

SECURITY NOTES
- Do not rotate APP_ENCRYPTION_KEY casually after Triple Whale keys are stored.
- If APP_ENCRYPTION_KEY changes, existing encrypted connected accounts cannot be decrypted unless re-encrypted.
- Rotate development database password before production.
- Rotate Triple Whale key if it was exposed in screenshots/files/chat.
